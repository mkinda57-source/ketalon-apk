# KETALON — application Android

Application **KETALON — Stock et encaissements** de KETALON SARL (ventes, stock, encaissements, versements, frais et échantillons des commerciaux).

## Télécharger

**[KETALON.apk](https://github.com/mkinda57-source/ketalon-apk/raw/main/KETALON.apk)** — version 2.3 (13/11/2026), Android 5 ou plus récent.

Sur iPhone ou sur ordinateur, utilisez le site : https://ketalon.web.app

## Installer
1. Ouvrez le lien ci-dessus sur le téléphone Android, puis le fichier téléchargé.
2. Si le téléphone refuse : « Paramètres » → activez « Autoriser cette source », revenez, puis « Installer ».
3. Si Android affiche un avertissement : « Plus de détails » → « Installer quand même » (l'application ne vient pas du Play Store).
4. Connectez-vous avec l'identifiant et le mot de passe provisoire envoyés par le gérant, puis choisissez votre mot de passe.

Une nouvelle version s'installe par-dessus l'ancienne, sans rien perdre.
